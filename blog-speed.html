چرا سرعت سایت مهمه؟

سایتی که دیر باز بشه، قبل از اینکه دیده بشه بسته می‌شه.

سرعت فقط یه عدد فنی نیست؛ حس کاربر رو می‌سازه. گوگل برای اندازه‌گیری تجربه صفحه سه معیار به اسم Core Web Vitals داره.

سه معیار اصلی و عددهای «خوب»

  • LCP: مدت زمانی که بزرگ‌ترین بخش صفحه (معمولاً عکس یا تیتر اصلی) نمایش داده می‌شه. حد خوب: ۲.۵ ثانیه یا کمتر.
  • INP: سرعت واکنش صفحه به کلیک و لمس کاربر. حد خوب: ۲۰۰ میلی‌ثانیه یا کمتر.
  • CLS: میزان جابه‌جا شدن ناگهانی عناصر هنگام لود. حد خوب: ۰.۱ یا کمتر.

این عددها برای ۷۵ درصد بازدیدهای صفحه در نظر گرفته می‌شن.

چطور سایتم رو سریع‌تر کنم؟

طبق راهنمای web.dev، این کارها بیشترین اثر رو دارن:

  • عکس‌ها رو فشرده کن و از فرمت‌های جدید مثل WebP یا AVIF استفاده کن.
  • عکس اصلی بالای صفحه رو lazy-load نکن و بهش fetchpriority="high" بده.
  • ریدایرکت‌های اضافی رو حذف کن.
  • فایل CSS رو کوچیک نگه دار و اسکریپت‌هایی که فوری لازم نیستن رو با defer لود کن.
  • از کش و CDN استفاده کن.
یه نکته

با ابزار PageSpeed Insights گوگل می‌تونی سرعت سایتت رو رایگان بسنجی و ببینی کدوم قسمتش کند‌ه.
