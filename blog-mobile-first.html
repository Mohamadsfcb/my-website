چرا سایتت باید اول روی موبایل خوب باشه؟

اگه سایتت رو موبایل بد دیده بشه، برای گوگل هم بد دیده میشه.

گوگل برای ایندکس و رتبه دهی سایتها، نسخه موبایل محتوا رو بررسی میکنه. به این روش میگن «ایندکس موبایل محور» (mobile-first indexing).

بهترین راه: طراحی واکنشگرا

گوگل طراحی واکنشگرا (Responsive) رو توصیه میکنه؛ یعنی یه آدرس و یه HTML برای همه دستگاهها، که فقط نمایشش بسته به اندازه صفحه تغییر میکنه. اینطوری محتوای موبایل و دسکتاپ دقیقاً یکی میمونه.

چند نکته که گوگل میگه

  • محتوای اصلی نسخه موبایل باید با دسکتاپ یکی باشه.
  • محتوای اصلی رو پشت کلیک یا اسکرول lazy-load نکن.
  • فایل های CSS و JS و عکس ها رو با robots.txt مسدود نکن.
  • عنوان و توضیح صفحه و داده ساختاریافته در هر دو نسخه یکسان باشه.
  • عکس ها کیفیت خوب و متن alt یکسان داشته باشن.
  • آکاردئون و تبها برای جا شدن محتوا تو صفحه کوچیک اشکالی ندارن.

چطور تست کنم؟

سایتت رو رو گوشی واقعی باز کن، متنها رو بدون زوم بخون و ببین دکمهها راحت لمس میشن. یادت نره تگ viewport تو head صفحه باشه.

یه نکته

موقع طراحی از موبایل شروع کن و بعد برو سراغ صفحه های بزرگتر؛ اینطوری مجبور میشی فقط چیزهای مهم رو نگه داری.
